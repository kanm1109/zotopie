========================================
BƯỚC 1 - SUBMIT SITEMAP (LÀM NGAY)
========================================

1. Vào search.google.com/search-console
2. Chọn property zotopie.com
3. Menu trái → click "Sơ đồ trang web" (Sitemaps)
4. Nhập vào ô: sitemap-index.xml
5. Click "Gửi"

→ Google sẽ bắt đầu crawl và index website trong 1-7 ngày


========================================
BƯỚC 2 - THÊM WWW.ZOTOPIE.COM (NÊN LÀM)
========================================

1. Vào Cloudflare Dashboard → Workers & Pages → zotopie
2. Tab "Custom domains" → "Set up a custom domain"
3. Nhập: www.zotopie.com → Continue → Activate domain
4. Cloudflare tự thêm DNS record cho www

→ Đảm bảo cả www.zotopie.com cũng trỏ đúng vào website


========================================
BƯỚC 3 - CLOUDFLARE ANALYTICS (TÙY CHỌN)
========================================

Cloudflare tự động có analytics miễn phí, không cần cài gì thêm.

Xem thống kê tại:
→ Cloudflare Dashboard → Workers & Pages → zotopie → tab "Metrics"

Thấy được: lượt truy cập, quốc gia, bandwidth, request...


========================================
BƯỚC 4 - GOOGLE ANALYTICS 4 (TÙY CHỌN)
========================================

Nếu muốn tracking chi tiết hơn:

1. Vào analytics.google.com → tạo account mới
2. Tạo property → chọn "Web" → nhập zotopie.com
3. Lấy Measurement ID dạng: G-XXXXXXXXXX
4. Nhắn ID đó cho Claude → sẽ thêm vào code và push lên

→ Có thể bỏ qua nếu dùng Cloudflare Analytics là đủ


========================================
BƯỚC 5 - ĐĂNG BÀI VIẾT MỚI (WORKFLOW CHÍNH)
========================================

Mỗi lần muốn đăng bài:

a. Tạo file markdown mới trong thư mục phù hợp:
   - src/content/reddit/     ← bài về Reddit
   - src/content/threads/    ← bài về Threads
   - src/content/extensions/ ← bài về Extensions
   - src/content/marketing/  ← bài về Marketing
   - src/content/blog/       ← bài blog chung

b. Dùng ARTICLE_TEMPLATE.md làm mẫu (copy file đó ra)

c. Điền đầy đủ phần frontmatter:
   ---
   title: 'Tiêu đề bài viết'
   description: 'Mô tả 150-160 ký tự'
   publishDate: '2025-06-08'
   author: 'Zotopie Team'
   tags: ['tag1', 'tag2', 'tag3']
   category: 'reddit'
   draft: false
   ---

d. Mở PowerShell → chạy 3 lệnh:
   cd "H:\ca nhan\zotopie\zotopie"
   git add .
   git commit -m "publish: Tên bài viết"
   git push origin main

e. Chờ ~2 phút → Cloudflare tự build → bài live

→ URL bài viết sẽ là: zotopie.com/reddit/ten-file/


========================================
BƯỚC 6 - THEO DÕI GOOGLE INDEX
========================================

Sau khi đăng bài mới, muốn Google index nhanh:

1. Vào search.google.com/search-console
2. Dán URL bài viết vào ô tìm kiếm trên cùng
   Ví dụ: https://zotopie.com/reddit/reddit-marketing-guide-2025/
3. Click "Yêu cầu lập chỉ mục"

→ Google sẽ crawl bài đó trong vài giờ đến vài ngày


========================================
BƯỚC 7 - KIỂM TRA ĐỊNH KỲ
========================================

Mỗi tuần nên kiểm tra:

□ search.google.com/search-console
  → Xem bao nhiêu trang được index
  → Kiểm tra lỗi crawl nếu có

□ zotopie.com/sitemap-index.xml
  → Đảm bảo sitemap cập nhật bài mới

□ Cloudflare Pages → Deployments
  → Xác nhận mỗi lần push đều build thành công

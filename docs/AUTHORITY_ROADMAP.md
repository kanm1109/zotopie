## Implementation Plan

### Recommended approach: Hybrid static + data-driven

**Phase A — Build the infrastructure (1 sprint)**

1. Create `src/data/best-pages.json` — config file with per-page metadata:
   ```json
   [
     {
       "slug": "seo-tools",
       "title": "Best SEO Tools",
       "year": "2026",
       "description": "...",
       "categoryFilter": "seo-search",
       "pricingFilter": null,
       "toolSlugs": ["rank-math","ahrefs","surfer-seo","semrush","screaming-frog"],
       "intro": "...",
       "rankLabels": {
         "rank-math": "Best for WordPress",
         "ahrefs": "Best for Link Building"
       }
     }
   ]
   ```

2. Create `src/pages/best/[slug].astro` — dynamic route that:
   - Reads `best-pages.json` for the page config
   - Pulls tool data from `tools-enriched.json` by slug list
   - Generates: ranked list, comparison table, FAQ, related compare pairs
   - Adds correct JSON-LD (ItemList + FAQPage)
   - Title tag: "Best {title} in {year} — Ranked & Reviewed | Zotopie"

3. Add `/best/` index page at `src/pages/best/index.astro` — lists all best pages

**Phase B — Content pass (1-2 days per 5 pages)**

For each page, write:
- 1 intro paragraph (150 words): what the category is, who should read this guide
- Per-tool rank label: "Best for [use case]" (5 words max per tool)
- How we rank: shared snippet reused across all pages

**Phase C — Internal linking (1 sprint after all 20 pages live)**

- Homepage: add "Editor's Picks" section linking to top 5 best pages
- Category pages: add "Read our editorial guide →" CTA linking to corresponding best page
- Review pages: add "Explore the best [category] tools →" link in each review's related section
